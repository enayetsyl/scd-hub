## Reviewer notes (Mahzabin — read first)

**How to review.** Each tagged row (✓ in the "Tagged" column) is one thing a question can be tagged with. An objective with sub-objectives is not tagged itself — its sub-objectives add up into it, and guardians see only the objective label and home tip. For every row ask the five drafting tests: one short question can test it · the book practises it · it can be retaught on its own · it appears once in the class · it was split only because a child can pass one part and fail the other.

**Look at these first (Claude's judgement calls):**
1. **০৭-০২ has no sub-objectives**, unlike the example agreed with the owner. "ঘর মিলিয়ে বসানো" moved to the skill strand SK-COL-01 because subtraction needs the same skill; once the digits are lined up, "দুই অঙ্ক + এক অঙ্ক" and "দুই অঙ্ক + দুই অঙ্ক" are the same sum. Confirm, or ask for the split back.
2. **০৭-০৪ গল্পের যোগ has no sub-objectives either.** A story sum with carrying fails because of carrying (০৭-০৩.২), which is already its own row. Bank questions of that kind are written as ক/খ parts. Confirm.
3. **০৭-০১ has five sub-objectives, not four.** "১০-এর মধ্যে যোগ" (exercises ৩–৪) is separate from "১০ বানানো" (exercise ৫).
4. **শতকিয়া ("পাঁচ দশ তিন" → ৫৩) sits under place value (০৪-০১.২),** not under writing numbers, because it builds a number from tens and ones.
5. **নামতা (০৬-০১, ১১-০১) is split into three steps:** chorus, random recall, and writing in the গুণ-খালিঘর. The teacher note itself says chorus is not proof of knowing. The old strands SK-TABLE-01 and SK-MENT-01 are folded into these.
