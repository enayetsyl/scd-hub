## পর্যালোচকের নোট (মাহজাবিন — আগে পড়ুন)

**কীভাবে পড়বেন।** ✓ চিহ্নের প্রতিটি সারি একটি দক্ষতা — প্রশ্ন, বাড়ির কাজ ও রুব্রিক এই সারি ধরেই ট্যাগ হবে। ✓ ছাড়া শিখনফল শুধু দল; অভিভাবকেরা শিখনফলের নাম (ইংরেজিতে) ও বাংলা টিপ দেখবেন। আগের ধাপ তৃতীয় শ্রেণির কোডে (C3·…)। চতুর্থ শ্রেণির আগের কোনো ফ্ল্যাট খসড়া নেই — সব কোড নতুন। ব্যাকরণের সীমা লক করা C3–5 মই; বই নিজেও সিদ্ধান্ত ২০-এ ইউনিট ধরে E / CT / O লিখেছে, গাছ সেটাই মেনেছে।

**আগে এগুলো দেখুন (Claude-এর বিচার):**
1. **১৫ প্রশ্নের প্রতিটি এক জায়গায়, যে ইউনিটে বই শেখায় সেই কোডে:** প্র. ১/৩ → ০৩-০১, প্র. ২ → ০১-০৫, প্র. ৪/৫ → ০২-০২, প্র. ৬ → ০৩-০৩ (চার শ্রেণি / আটটি), প্র. ৭ → ০৫-০১, প্র. ৮ → ০১-০৪ (চার ধাপ), প্র. ৯ → ১৩-০১, প্র. ১০ → ০৪-০২, প্র. ১১ → ০৬-০২ + ০৭-০১ + ১৩-০৩, প্র. ১২ → প্রতিটি কাল নিজের ইউনিটে (০১-০৩, ০৩-০৪, ০৯-০৪, ১৩-০২), প্র. ১৩ → ০৪-০৩ (সংলাপ) / ১০-০১ (চিঠি), প্র. ১৪ → SK-WRITE-01, প্র. ১৫ → ১৫-০১।
2. **প্র. ১২ এক সারি নয়, কাল ধরে চার শিখনফল** — শিশু simple present পারে কিন্তু past-এ ভুল করে; অভিভাবক কালের নাম দেখবেন। Exam Practice-এর মেশানো কালের অনুশীলনী যে কালে শেষ, সেখানে (ক/খ নোট)।
