## Question types & marks (book mark distribution)
Both papers use the same 14 questions (decision 88). Half-yearly: Units 1–4. Annual: Q1–Q3 from Units 5–8; Q6–Q12 the whole year. The mark table is the plan; the setter may move a few marks, total 100 (decision 105). One row per code.

| Code | Question type (as in book) | Marks each | Answer form | Where in the book's exams | Notes |
|---|---|---|---|---|---|
| QT-TF | True / false — seen text | 1 | True / False | Q1 (5 × 1 = 5), set as true / false or as QT-MATCH | Mark on True / False alone; correction not needed; wrong answer 0 (decision 120) |
| QT-MATCH | Match words with meanings — seen text | 1 | match | Q1 (5 × 1 = 5), set as matching or as QT-TF | Matching requests with answers (U3 L3 D) is classwork |
| QT-MAKESENT | Make sentences with the given words | 2 | one sentence per word | Q2 (5 × 2 = 10) | Words to Know of the examined units (decisions 100, 103) |
| QT-ANSWER | Answer the questions | 2 | full sentence | Q3 seen text (7 × 2 = 14); Q5 unseen passage (3 × 2 = 6) | Full sentence 2; word or phrase only 1 (decisions 89, 40). HY Q3: two of three Unit 1–2 texts printed; annual: one of eight passages |
| QT-FILLBOX | Unseen passage: fill the gaps with words from the box | 1 | word from the box | Q4 (7 × 1 = 7) | Always a new passage (decision 93); box fill-ins on seen texts are classwork |
