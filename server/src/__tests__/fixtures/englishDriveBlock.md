# Class 1 (Sunday) — Plurals: making more than one

**Objective.** Students form regular plurals and the held irregulars.

### Step 1 — What a plural is (0–5 min)

**Books closed.** Write on the board:

```
one flower  →  two flowers
# not a heading — this is board work inside a fence
```

> "You have known this since Class 1."

### Step 6 — CW-1 (33 min)

Distribute CW-1. Model item 1 on the board.

# Class 2 (Monday) — Can I count this?

**Objective.** Students sort nouns into countable and uncountable.

### Step 6 — Clue Card + CW-2 (30–32 min)

Build rows 1–3 of the Countability Chart with the class.
